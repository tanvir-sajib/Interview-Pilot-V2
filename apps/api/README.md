# Interview Coach API

NestJS-based backend serving the Interview Coach platform.

## Available Scripts

- `npm run dev`: Starts the development server with hot reloading.
- `npm run build`: Compiles the TypeScript sources to `dist/`.
- `npm run start`: Runs the built production bundle.

## API Versioning
All public endpoints are prefixed with `/api/v1` once the API layer is fully implemented.
